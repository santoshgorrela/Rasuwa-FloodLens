
# Rasuwa FloodLens

## Rapid Flood Mapping & Infrastructure Impact Assessment

Rasuwa FloodLens is a satellite-based flood mapping and
impact assessment project focused on the August 2026
Rasuwa flood event in Nepal.

## Problem

The project aims to rapidly identify flood-affected areas
using Sentinel-1 SAR imagery and assess potentially affected
infrastructure.

## Study Area

Rasuwa District, Nepal

## Main Technology

- Google Earth Engine
- Sentinel-1 SAR
- Sentinel-2
- OpenStreetMap
- Geospatial analysis
- Interactive dashboard

## Main Data

### Sentinel-1 SAR
Used for flood detection and before/after change analysis.

### Sentinel-2
Used for optical visualisation and validation.

### OpenStreetMap
Used for infrastructure impact analysis, including:
- Roads
- Buildings
- Bridges
- Settlements

## Workflow

Satellite Data
→ Image Processing
→ Flood Detection
→ Geospatial Analysis
→ Impact Assessment
→ Interactive Dashboard
→ Decision Support

## Expected Outputs

- Pre-flood satellite image
- Post-flood satellite image
- Flood extent map
- Flooded area statistics
- Affected road analysis
- Affected settlement/building analysis
- Bridge/infrastructure exposure
- Interactive web dashboard

## Project Goal

To demonstrate how freely available satellite imagery
and geospatial analysis can support rapid flood assessment
and disaster-response decision making.
